# Zldrop

Серверный мод на аирдропы с автоспавном, зоной выпадения, самолетом-имитацией и настраиваемым лут-контейнером.

## Что умеет мод

- Создает отдельные аирдропы с уникальными именами.
- Позволяет задать область, внутри которой будет выбираться случайная точка спавна.
- Может сбрасывать аирдроп с самолета или ставить контейнер сразу на землю.
- Поддерживает свой лут-пул для каждого аирдропа.
- Поддерживает выбор любого блока аирдропа, включая модовые блоки.
- Умеет автоматически респавнить аирдроп по таймеру.

## Что такое область аирдропа

Область аирдропа это прямоугольная зона между двумя точками `pos1` и `pos2`.

Она нужна для того, чтобы мод не спавнил контейнер в одной и той же точке. При каждом новом спавне мод случайно выбирает позицию внутри этой зоны, ищет подходящую поверхность и уже туда отправляет аирдроп.

По сути:

- `pos1` и `pos2` задают границы по `X` и `Z`.
- Высота подбирается автоматически по поверхности мира.
- Если точка занята, в воде или на плохом блоке, мод пробует другие позиции.

## Как работает спавн

Если у аирдропа включена имитация:

1. Мод выбирает случайную точку в заданной области.
2. Самолет появляется в стороне от цели и летит через нее.
3. В точке сброса создается визуальный контейнер.
4. Контейнер опускается вниз.
5. После приземления визуал заменяется на настоящий блок-контейнер с лутом.
6. Самолет долетает остаток маршрута и исчезает.

Если имитация выключена:

1. Мод сразу ставит контейнер в найденную точку.
2. Наполняет его лутом.
3. При необходимости отправляет сообщение игрокам.

## Настройка аирдропа

Базовый порядок такой:

1. Создать аирдроп.
2. Открыть редактор лута и положить туда предметы.
3. Настроить количество случайных предметов.
4. Выделить область спавна.
5. При необходимости выбрать контейнерный блок.
6. Настроить респавн и сообщение.

## Команды

### Создание и удаление

- `/zldrop create <name>` - создать новый аирдроп.
- `/zldrop delete <name>` - удалить аирдроп.

### Лут

- `/zldrop edit <name>` - открыть GUI редактора лута.
- `/zldrop items <name> <count>` - указать, сколько случайных предметов будет выбрано из лут-пула.

Если в редакторе лежит 20 предметов, а `count = 3`, то при спавне в контейнер попадут случайные 3 предмета из этих 20.

### Сообщение и оформление

- `/zldrop prefix <name> <text>` - задать префикс/название контейнера.
- `/zldrop message <name> <text>` - задать сообщение при приземлении.
- `/zldrop message <name> off` - отключить сообщение.

В сообщении доступны плейсхолдеры:

- `{prefix}` - префикс аирдропа.
- `{coordinates}` - координаты приземления.

### Самолет

- `/zldrop imit <name> <true|false>` - включить или выключить имитацию самолета.

### Блок аирдропа

- `/zldrop container <name> <block_id>` - выбрать блок, который станет контейнером аирдропа.

Примеры:

- `/zldrop container military minecraft:barrel`
- `/zldrop container military minecraft:chest`
- `/zldrop container military modid:custom_crate`

Важно:

- Блок должен быть зарегистрирован в игре.
- Блок может быть любым, инвентарь самого блока не используется.
- При открытии аирдропа игроки видят общее серверное GUI на 54 слота.
- Если один игрок забирает предмет, он сразу пропадает у всех остальных.
- Модовые блоки поддерживаются так же, как и ванильные.

### Респавн

- `/zldrop respawn <name> <time>` - задать интервал автоспавна.

Примеры времени зависят от парсера мода, но обычно это форматы вроде:

- `30m`
- `1h`
- `2h30m`

### Область

- `/zldrop pos <name> <pos1> <pos2>` - задать две точки области спавна.

Пример:

1. Встать в первой точке зоны.
2. Запомнить координаты.
3. Перейти во вторую точку.
4. Выполнить команду с двумя позициями.

Пример команды:

`/zldrop pos military 100 64 100 300 80 300`

После этого мод будет искать место для аирдропа внутри этой зоны.

## Быстрый пример настройки

1. `/zldrop create military`
2. `/zldrop edit military`
3. Положить предметы в открывшийся инвентарь и закрыть его.
4. `/zldrop items military 4`
5. `/zldrop container military minecraft:barrel`
6. `/zldrop pos military 100 64 100 300 80 300`
7. `/zldrop respawn military 1h`
8. `/zldrop imit military true`
9. `/zldrop message military &8[&cAirDrop&8] &f{prefix} приземлился на &6{coordinates}`

## Полезные замечания

- Если область не задана, аирдроп не сможет заспавниться.
- Если подходящая поверхность внутри области не найдена, спавн будет пропущен.
- Блок аирдропа служит только визуалом на земле, лут хранится отдельно в общем GUI аирдропа.
- При выключенной имитации самолет и визуальный сброс не используются.

## Конфиг

У мода есть `common`-конфиг для самолета.

Параметр:

- `plane.trackingRange` - клиентская дальность отображения самолета для игроков.

Значение по умолчанию:

- `128`

Серверная tracking-дистанция самолета зафиксирована в коде на `128`, а этот конфиг управляет именно тем, с какого расстояния клиент перестанет его рисовать.

## Встроенная помощь

В игре доступна команда:

- `/zldrop`
- `/zldrop help`

Она выводит краткую справку по всем основным подкомандам.
